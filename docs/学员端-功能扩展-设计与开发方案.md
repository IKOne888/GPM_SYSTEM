# GMP 培训系统 · 学员端功能扩展 设计与开发方案

> 版本：v1.0
> 日期：2026-10-12
> 适用范围：`frontend-student`（学员端，EMPLOYEE 角色）+ `backend` 的 `/study/**` 接口
> 关联文档：[PC用户端-学员端-设计与开发方案.md](./PC用户端-学员端-设计与开发方案.md)（基础版，本次在其上扩展）

---

## 1. 背景与目标

### 1.1 背景

基础版学员端仅有「我的任务 + 个人中心」，侧栏「在线学习 / 在线考试」两项因依赖具体任务上下文，点击后只能弹出提示、无法跳转，属于无效入口。

### 1.2 目标

1. 移除「在线学习 / 在线考试」两个无效菜单项，学习与考试统一从「我的任务」进入。
2. 新增 7 个功能模块，充实学员端能力，覆盖「看数据 → 学课程 → 练错题 → 查资料 → 收消息」的完整闭环。
3. 所有新增能力复用现有数据表与 `/study/**` 权限模型，不引入新的鉴权体系。

### 1.3 本次新增模块一览

| # | 模块 | 路由 | 是否需改后端 | 说明 |
|---|------|------|-------------|------|
| 1 | 学习看板 | `/analysis` | 需新增 1 个聚合接口 | ECharts 数据可视化 |
| 2 | 课程中心（自主选学） | `/courses` | 需新增 3 个接口 | 浏览课程并自主报名 |
| 3 | 培训日历 | `/calendar` | 需新增 1 个接口 | 月历展示任务/考试节点 |
| 4 | 错题本与题库练习 | `/wrong-book` | 需新增表 + 4 个接口 | 错题自动收集与重做 |
| 5 | 资料中心 | `/materials` | 需新增 1 个接口 | 汇总课程资料统一下载 |
| 6 | 消息中心 | `/messages` | 复用 + 小幅扩展 | 独立消息页面 |
| 7 | 帮助中心 | `/help` | 不需要 | 纯静态内容 |

## 3. 数据模型变更

### 3.1 新增表：错题本 `tr_wrong_question`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 主键 |
| user_id | bigint NOT NULL | 学员ID |
| question_id | bigint NOT NULL | 题目ID（`tr_question.id`） |
| course_id | bigint | 课程ID（冗余，便于按课程筛选） |
| wrong_count | int DEFAULT 1 | 累计答错次数 |
| last_wrong_time | datetime | 最近答错时间 |
| mastered | tinyint DEFAULT 0 | 是否已掌握：0-否 1-是 |
| last_practice_correct | tinyint DEFAULT 0 | 最近一次练习是否答对 |
| create_time / update_time | datetime | 时间戳 |

唯一键：`uk_user_question (user_id, question_id)`，索引 `idx_user_id`、`idx_course_id`。

**写入时机**：`StudyServiceImpl.submitExam()` 判分时，对每道 `is_correct = 0` 的题执行 upsert（`wrong_count + 1`、`mastered = 0`）；错题重做答对后由练习接口置 `mastered = 1`。

### 3.2 字段变更：`tr_training_task` 增加 `source`

| 字段 | 类型 | 说明 |
|------|------|------|
| source | tinyint DEFAULT 1 | 任务来源：1-系统分配（计划/管理员） 2-自主报名 |

用于区分「计划分配」与「课程中心自主报名」，便于后续统计与筛选。存量数据默认 1。

### 3.3 无需变更

- `sys_message`：已有 `user_id / title / content / message_type / is_read / related_id`，满足消息中心页面需求。
- `tr_course_file` / `tr_course_pdf`：满足资料中心需求。
- `tr_course`：`department_id / position_id / category_id` 满足课程中心按部门-岗位推荐。

## 4. 后端接口契约（新增部分）

**通用约定**（与基础版一致，不再赘述）：
- 统一前缀 `/study`，返回 `Result<T>`，`code = 200` 为成功；
- 仅做登录校验，数据隔离在 Service 层用 `StpUtil.getLoginIdAsLong()` 强制；
- 分页参数 `page`（默认 1）/ `size`（默认 10，`@Max(100)`）。

### 4.1 学习看板

**`GET /study/analysis/overview`** — 一次性返回看板全部数据

```json
{
  "code": 200,
  "data": {
    "totalStudyDuration": 5400,      // 累计学习时长（秒）
    "totalTask": 5,                  // 任务总数
    "completedTask": 3,              // 已完成
    "studyingTask": 0,               // 学习中
    "overdueTask": 2,                // 已逾期
    "certificateCount": 1,           // 证书数
    "avgScore": 88,                  // 平均成绩
    "passRate": 100,                 // 通过率（百分比）
    "monthly": [                     // 近 6 个月趋势
      { "month": "2026-05", "studyDuration": 1200, "examCount": 2, "passCount": 2 }
    ],
    "statusDist": [                  // 任务状态分布（饼图）
      { "status": 3, "count": 3 }
    ],
    "scoreDist": [                   // 成绩分布（柱状图）
      { "range": "0-59", "count": 0 },
      { "range": "60-69", "count": 0 },
      { "range": "70-79", "count": 0 },
      { "range": "80-89", "count": 1 },
      { "range": "90-100", "count": 2 }
    ]
  }
}
```

> 逾期数量为**动态计算**（`deadline < now && status != 3`），不落库，与基础版一致。

### 4.2 课程中心

**`GET /study/courses`** — 课程列表（分页）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page / size | int | 否 | 分页 |
| keyword | string | 否 | 课程名称模糊搜索 |
| categoryId | long | 否 | 分类筛选 |
| enrolled | boolean | 否 | true-只看已报名，false-只看未报名，不传-全部 |

返回 `Page<StudyCourseVO>`，元素字段：`id, name, code, categoryName, sopCode, sopVersion, trainingHours, passScore, retrainPeriod, objective, enrolled(boolean), taskId(已报名时的任务ID)`。

**推荐逻辑**：优先返回 `department_id = 当前用户部门 或 position_id = 当前用户岗位 或 两者为空（全校通用）` 的启用课程。

**`GET /study/courses/{id}`** — 课程详情
返回字段同上，另含：`fileCount`（资料数）、`videoCount`（视频数）、`questionCount`（题目数）、`departmentName`、`positionName`。

**`POST /study/courses/{id}/enroll`** — 自主报名

- 前置校验：
  1. 课程存在且 `status = 1`；
  2. 当前用户**不存在**该课程下 `status != 3` 的任务，否则报错「该课程已有进行中的学习任务」；
  3. 同一课程已完成但仍在复训周期内 → 允许报名（复用基础版证书有效期逻辑）。
- 成功行为：插入 `tr_training_task`（`source = 2`、`task_type = 1`、`status = 0`、`video_progress = 0`、`study_duration = 0`、`max_retry = 3`），`deadline` 取「当前时间 + 课程复训周期」，若课程未配置复训周期则 `deadline` 为空。
- 返回：`{ "taskId": 12 }`

### 4.3 培训日历

**`GET /study/calendar`** — 按日期区间返回事件

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| startDate | date | 是 | 起始日期（含），格式 `yyyy-MM-dd` |
| endDate | date | 是 | 结束日期（含），跨度不得超过 62 天 |

```json
{
  "code": 200,
  "data": [
    {
      "date": "2026-10-20",
      "events": [
        { "type": 1, "title": "GMP基础培训 截止", "taskId": 6, "courseId": 1, "time": "2026-10-20 23:59:59", "status": 0 },
        { "type": 2, "title": "GMP基础培训 考试", "taskId": 6, "recordId": 4, "time": "2026-10-12 10:00:00", "status": 1 }
      ]
    }
  ]
}
```

事件类型：`1-任务截止`（取 `tr_training_task.deadline`）、`2-考试安排`（取 `tr_exam_record.start_time`）。返回结果仅包含有事件的日期。

### 4.4 错题本与题库练习

**`GET /study/wrong-questions`** — 错题列表（分页）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page / size | int | 否 | 分页 |
| courseId | long | 否 | 按课程筛选 |
| questionType | int | 否 | 按题型筛选（1~5） |
| mastered | boolean | 否 | 默认 false（只看未掌握） |

元素字段：`id（错题记录ID）, questionId, courseId, courseName, questionType, content, options[], correctAnswer, analysis, myAnswer（最近一次错误答案）, wrongCount, lastWrongTime, mastered`。

**`GET /study/wrong-questions/stats`** — 错题统计
返回：`{ total, notMastered, mastered, byType: [{questionType, count}], byCourse: [{courseId, courseName, count}] }`

**`POST /study/wrong-questions/practice`** — 错题重做提交（单题即时判分）

```json
// 请求
{ "questionId": 15, "answer": "AB" }
// 响应
{ "correct": true, "correctAnswer": "AB", "analysis": "...", "mastered": true }
```

判分规则**复用基础版**：多选字母忽略顺序（`normalizeLetters` 排序后比较）、判断题归一化（`正确/对/A/TRUE/T/1 → 正确`）。答对则将该错题置 `mastered = 1`。

**`DELETE /study/wrong-questions/{id}`** — 手动移除错题（标记已掌握）

### 4.5 资料中心

**`GET /study/materials`** — 资料汇总（分页）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page / size | int | 否 | 分页 |
| courseId | long | 否 | 按课程筛选 |
| fileType | string | 否 | PDF/DOC/DOCX/XLS/XLSX |
| keyword | string | 否 | 资料名称搜索 |

元素字段：`id, name, fileName, fileType, fileSize, courseId, courseName, uploadTime`。

**范围限定**：仅返回「当前用户存在培训任务（任意状态）或已完成课程」所关联课程的 `status = 1` 资料，避免越权访问未授权课程资料。

**下载/预览**：复用 `GET /study/courses/files/{fileId}/url` 获取 MinIO 预签名地址。

### 4.6 消息中心

**复用**：`GET /study/messages`、`GET /study/messages/unread-count`、`POST /study/messages/{id}/read`、`POST /study/messages/read-all`。

**需扩展**：`GET /study/messages` 增加可选参数 `messageType`（1~4）与 `isRead`（boolean），用于页面筛选；不传时保持原行为（不影响顶部铃铛）。

**交互**：点击消息 → 若 `related_id` 非空且 `message_type ∈ {1,2,3}`，跳转对应任务详情 `/task/{relatedId}`。

### 4.7 帮助中心

不需要后端接口。内容由前端静态数据渲染，包含：培训制度要点、学习流程指引、常见问题（FAQ）、技术支持联系方式。

## 5. 前端页面设计

统一遵循基础版的视觉令牌（`--brand-primary: #1677FF`、`--brand-gradient`、`--bg-page: #F0F5FA`、`.gmp-card`）与卡片化布局。

| 页面 | 主要内容 |
|------|---------|
| 学习看板 | 4 个指标卡 + 3 个 ECharts（月度趋势折线、任务状态环形、成绩分布柱状）+ 空数据占位 |
| 课程中心 | 筛选栏（关键词/分类/报名状态）+ 课程卡片网格（学时、SOP、及格分、复训周期）+ 报名按钮 |
| 课程详情 | 课程信息卡 + 培训目标 + 资料/视频/题目数量 + 「立即学习」按钮（报名后跳任务详情） |
| 培训日历 | Element Plus 日历 + 日期单元格事件标记 + 右侧当日事件清单 + 「近期到期」列表 |
| 错题本 | 统计卡（错题总数/未掌握/已掌握）+ 筛选栏 + 错题列表（展开查看解析）+ 「开始练习」入口 |
| 错题练习 | 单题答题卡模式，提交即时反馈对错与解析，答对自动移出错题本 |
| 资料中心 | 筛选栏 + 表格（名称/课程/类型/大小/上传时间/操作）+ 预览与下载 |
| 消息中心 | 左侧消息类型筛选 + 消息列表（未读加粗、圆点标记）+ 单条/全部已读 + 点击跳转 |
| 帮助中心 | 锚点导航 + 制度要点 + 学习流程步骤条 + FAQ 折叠面板 + 联系方式 |

新增 API 封装：`src/api/analysis.js`、`src/api/course.js`、`src/api/calendar.js`、`src/api/wrongbook.js`、`src/api/material.js`；消息相关沿用 `src/api/profile.js`。

ECharts 按需引入（`echarts/core` + 折线/柱状/饼图 + Canvas 渲染器），避免整包体积膨胀。

## 6. 权限与安全

1. 全部新增接口位于 `/study/**`，仅要求登录，不额外配置角色（与基础版一致）。
2. **数据隔离强制在 Service 层**：所有查询以 `StpUtil.getLoginIdAsLong()` 为条件，禁止从前端接收 `userId`。
3. 报名接口需做幂等与状态校验，防止重复创建任务。
4. 资料下载仅限用户已关联课程，预签名 URL 有效期沿用基础版配置。
5. `DELETE /study/wrong-questions/{id}` 需校验该错题记录归属当前用户。

## 8. 验收标准

1. 侧栏不再出现「在线学习 / 在线考试」，其余菜单**点击均能正常跳转**（无「点了没反应」）。
2. 学习看板 4 个指标与 3 个图表数据与「我的任务 / 学习记录」一致，无数据时展示友好占位。
3. 课程中心可浏览、可报名；报名后「我的任务」立即出现该任务，重复报名被拒绝并给出中文提示。
4. 培训日历能正确标记任务截止与考试日期，切换月份数据随动。
5. 考试故意答错 → 错题本出现该题；重做答对后该题移出未掌握列表。
6. 资料中心仅能看到自己有任务关联课程的资料，下载可正常打开。
7. 消息中心筛选、单条已读、全部已读均生效，顶部铃铛未读数同步刷新。
8. 帮助中心内容完整、无控制台报错。
9. `npm run build` 通过；`/study/**` 新增接口在 Postman/curl 下均返回 `code = 200`；
10. 管理端（`/training/**`、`/exam/**`）功能不受影响（回归验证）。
