## 1. 背景与目标

- 技术栈：Spring Boot 2.7 + MyBatis-Plus + MySQL 8 + Redis + Sa-Token + MinIO（后端）；Vue3 + Vite + Element Plus + Pinia（前端 `frontend-pc`）。
- 当前问题：登录已修复；但前端各页面调用的接口路径/方法与后端不一致（后端非 RESTful，前端 RESTful），且培训计划/任务、考试、操作日志、视频分片上传等后端代码缺失，导致点击菜单报 404/405/500。
- 本轮目标：**对齐接口 + 补齐缺失后端模块 + 新增文件/视频上传与在线观看**，使核心页面全部可用。

## 3. 数据库设计变更

### 3.1 调整：岗位归属部门（支撑"部门-岗位"分类）

`sys_position` 目前是全局岗位，无法表达"运维部门下的 pos 类"。新增字段：

```sql
ALTER TABLE sys_position ADD COLUMN department_id BIGINT DEFAULT NULL COMMENT '所属部门ID' AFTER code;
ALTER TABLE sys_position ADD INDEX idx_department_id (department_id);
```

### 3.2 调整：课程归属部门与岗位（分类核心）

```sql
ALTER TABLE tr_course ADD COLUMN department_id BIGINT DEFAULT NULL COMMENT '归属部门ID' AFTER category_id;
ALTER TABLE tr_course ADD COLUMN position_id   BIGINT DEFAULT NULL COMMENT '归属岗位类别ID' AFTER department_id;
ALTER TABLE tr_course ADD INDEX idx_department_id (department_id);
ALTER TABLE tr_course ADD INDEX idx_position_id (position_id);
```

- 视频（`tr_course_video`）通过 `course_id` 关联课程，**继承课程的部门/岗位分类**，无需重复加字段。
- 学员可见性 = 课程 `department_id`/`position_id` 与学员自身 `department_id`/`position_id` 匹配（同部门可见、同岗位可见；两者都不限或为空表示公共）。

### 3.3 新增：通用课程资料文件表（"上传文件"功能）

> 说明：`tr_course_pdf` 仅限 PDF。若上传文件含 PPT/Word/Excel/PDF 等多类型，新增通用表；否则可复用 `tr_course_pdf`。
> **待你确认第 3 题"文件上传用途"后二选一**（默认按"课程资料附件"设计，新增下表）。

```sql
CREATE TABLE `tr_course_file` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `course_id` bigint NOT NULL COMMENT '课程ID',
  `name` varchar(200) NOT NULL COMMENT '资料名称',
  `file_name` varchar(200) NOT NULL COMMENT '原始文件名',
  `file_path` varchar(500) NOT NULL COMMENT 'MinIO对象路径',
  `file_size` bigint DEFAULT NULL COMMENT '文件大小（字节）',
  `file_type` varchar(20) DEFAULT NULL COMMENT '文件后缀（pdf/ppt/docx/xlsx…）',
  `upload_user_id` bigint NOT NULL COMMENT '上传人ID',
  `upload_time` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '上传时间',
  `status` tinyint DEFAULT 1 COMMENT '状态：0-禁用 1-启用',
  `deleted` tinyint DEFAULT 0 COMMENT '逻辑删除',
  PRIMARY KEY (`id`),
  KEY `idx_course_id` (`course_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课程资料文件表';
```

> 若"文件"用于学员提交作业，则改为 `tr_task_attachment(task_id,user_id,…)` 设计，待确认。

## 4. 权限与分类模型

### 4.1 角色

- `SUPER_ADMIN` 超级管理员、`QA_MANAGER` 质量管理员、`TRAINING_ADMIN` 培训管理员、`DEPT_LEADER` 部门负责人、普通用户（学员）。

### 4.2 接口权限（Sa-Token）

| 范围 | 规则 |
|---|---|
| 上传（文件/视频/资料） | `SUPER_ADMIN / QA_MANAGER / TRAINING_ADMIN` |
| 课程/计划/任务/考试/岗位/部门 管理 | `SUPER_ADMIN / QA_MANAGER / TRAINING_ADMIN`（部门管理可含 DEPT_LEADER） |
| 观看/播放（学员，只读） | 任意登录用户 |
| 操作日志查询 | `SUPER_ADMIN / QA_MANAGER` |

### 4.3 分类可见性规则

- 课程/视频带 `department_id`（必填）、`position_id`（选填）。
- 学员列表可见 = `department_id = 我的部门` OR `position_id = 我的岗位` OR 公共(空)。
- 管理员列表可见 = 全部（可按部门/岗位筛选）。
