## 1. 背景与目标

### 1.1 背景

系统当前为「单后端 + 双 PC 前端」架构：

| 端 | 工程 | 端口 | 说明 |
| --- | --- | --- | --- |
| 后端 | `backend` | 8080 | context-path 为 `/api`，管理端与学员端接口共存 |
| 管理端 | `frontend-pc` | 3000 | 管理员使用，`/training/**`、`/exam/**`、`/system/**` |
| 学员端（PC） | `frontend-student` | 3002 | 员工使用，统一走 `/study/**` |
| 小程序端 | `miniprogram` | — | 无独立后端，复用 `/study/**` |

`miniprogram` 目录此前仅有骨架，且存在三类必须修正的问题：

1. **接口错用**：页面调用的是管理端接口（`/training/task/my`、`/system/user/login` 等），未使用学员端 `/study/**` 接口。
2. **鉴权错用**：请求头错误地拼接了 `Bearer ` 前缀；后端 Sa-Token 的 `token-name` 为 `Authorization` 且**未配置 token-prefix**，必须直接传原始 token，否则会返回「未登录或登录已过期」。
3. **登录缺失验证码**：登录接口 `POST /auth/login` 要求携带图形验证码（`captchaKey` + `captchaCode`），而现有登录页仅有账号密码。
4. **页面缺失**：`app.json` 已注册 `pages/exam/*`、`pages/profile/*` 等页面，但对应文件不存在，导致开发者工具编译报错；`pages/video/play.json` 亦缺失。

### 1.2 目标

1. **全面对齐学员端接口**：所有页面统一使用 `/study/**`（共 34 个接口），鉴权方式与 PC 学员端保持一致（原始 token）。
2. **补齐登录闭环**：图形验证码 + 账号密码登录，登录成功缓存 token 与脱敏用户信息。
3. **补齐页面**：我的任务、在线学习、在线考试、个人中心/培训档案、消息中心、课程中心。
4. **工程可用**：`app.json` 注册的页面全部存在，tabBar 配置可用（无遗留图标引用）。

## 2. 总体设计

### 2.1 登录与鉴权方案

```
用户输入账号密码 → GET /auth/captcha 取 captchaKey + captchaImage(base64)
                → POST /auth/login {username,password,captchaKey,captchaCode}
                → Result<LoginVO>{ token, user }  → 本地缓存 → 进入首页
```

- **token 存储**：`wx.setStorageSync('student_token', token)`；用户信息存 `student_userInfo`。
  （与 PC 学员端键名保持一致，语义清晰、避免与其它端混淆。）
- **请求头**：`Authorization: <原始token>`，**不加 `Bearer ` 前缀**。
- **失效处理**：接口返回 `code=401` 时清除本地登录信息并跳转登录页。
- **白名单**：`/auth/captcha`、`/study/videos/{id}/stream` 无需 token。
  其中视频流由小程序 `<video>` 直接访问，因此采用 **URL 直连** `baseUrl + /study/videos/{id}/stream`。

### 2.2 目录与页面清单

| 页面路径 | 功能 | 主要接口 |
| --- | --- | --- |
| `pages/login/index` | 登录（验证码） | `GET /auth/captcha`、`POST /auth/login` |
| `pages/index/index` | 我的任务（tabBar） | `GET /study/tasks`、`/study/tasks/stats`、`/study/messages/unread-count` |
| `pages/task/list` | 全部任务（搜索/筛选/分页） | `GET /study/tasks` |
| `pages/task/detail` | 任务详情 | `GET /study/tasks/{id}` |
| `pages/video/play` | 在线学习（倍速/续播/进度上报） | `GET /study/tasks/{id}/videos`、`GET /study/videos/{videoId}/record`、`POST /study/videos/progress`、`GET /study/videos/{id}/stream` |
| `pages/exam/enter` | 考试须知 | `GET /study/tasks/{taskId}/exam`、`POST /study/exams/{taskId}/start` |
| `pages/exam/test` | 在线答题（倒计时/答题卡） | `GET /study/exams/records/{recordId}`、`POST /study/exams/records/{recordId}/submit` |
| `pages/exam/result` | 成绩与解析 | `GET /study/exams/records/{recordId}/result` |
| `pages/course/list` | 课程中心（tabBar，自主选学） | `GET /study/courses` |
| `pages/course/detail` | 课程详情与报名 | `GET /study/courses/{id}`、`POST /study/courses/{id}/enroll` |
| `pages/message/list` | 消息中心 | `GET /study/messages`、`PUT /study/messages/{id}/read`、`PUT /study/messages/read-all` |
| `pages/profile/index` | 个人中心（tabBar） | `GET /study/profile`、`PUT /study/profile`、`PUT /study/profile/password` |
| `pages/profile/record` | 学习记录 + 成绩单 | `GET /study/records/study`、`GET /study/records/exam` |
| `pages/profile/certificate` | 培训档案 / 证书 | `GET /study/records/certificate` |

> 说明：本期小程序聚焦「我的任务 / 在线学习 / 在线考试 / 个人中心与培训档案」四大核心模块，
> 并补充课程中心与消息中心；学习看板、培训日历、错题本、资料中心等 PC 端增强功能暂不在小程序落地（可作为后续迭代）。

### 2.3 tabBar 设计

小程序 tabBar 采用**纯文字**配置（不引用图标资源，避免缺失图片导致的编译告警）：

| 顺序 | 页面 | 文案 |
| --- | --- | --- |
| 1 | `pages/index/index` | 我的任务 |
| 2 | `pages/course/list` | 课程中心 |
| 3 | `pages/profile/index` | 个人中心 |

### 2.4 公共能力（utils/request.js）

| 方法 | 说明 |
| --- | --- |
| `request(url, method, data, options)` | 统一请求，自动注入 token、统一处理 `Result{code,message,data}` |
| `get/post/put/del` | 快捷方法 |
| `getToken/setAuth/clearAuth` | 本地认证信息读写 |
| `getTaskStatusText(status) / getTaskStatusClass(status)` | 任务状态（字符串枚举）→ 中文/样式类 |
| `formatTime / formatDuration` | 时间格式化（统一 `yyyy-MM-dd HH:mm:ss` 口径的裁剪版）、秒 → `mm:ss` |
| `buildVideoUrl(videoId)` | 拼接视频流地址（走白名单，无需 token） |

**任务状态口径**：后端 `StudyTaskVO.status` 为字符串枚举
`not_started / studying / waiting_exam / completed / overdue`，
同时提供 `statusCode`（0~4）。小程序统一以 **字符串枚举** 判定状态与配色。

## 3. 关键交互设计

### 3.1 在线学习（视频播放）

- **播放地址**：`baseUrl + /study/videos/{id}/stream`（后端支持 HTTP Range，可拖动进度）。
- **断点续播**：进入时读取 `GET /study/videos/{videoId}/record?taskId=`，`lastPosition>0` 时弹窗询问是否续播。
- **进度上报**：`POST /study/videos/progress`，字段 `{taskId, videoId, progress, lastPosition, studyDuration}`
  （注意：字段名为 `progress`，非 `videoProgress`）。
  上报时机：每 15 秒、暂停、切页（`onHide`）、播放结束（`onEnded`）。
- **倍速**：0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x。
- **防挂机**：30 秒无操作暂停并弹窗确认「我仍在观看」。

### 3.2 在线考试

- **须知页**：展示试卷名、题量、总分/及格分、时长、剩余考试次数、上次成绩；`canExam=false` 时禁用按钮并显示 `reason`。
- **开始考试**：`POST /study/exams/{taskId}/start` 返回 `recordId` 与题目列表（**不含答案**），随后进入答题页。
- **答题页**：以 `recordId` 为主键，`GET /study/exams/records/{recordId}` 取回题目与已作答内容（刷新恢复）。
  倒计时以服务端 `remainSeconds` 为准，归零自动交卷。
- **答案格式**（与后端判分口径严格一致）：
  - 单选（type=1）：选项字母 `A/B/C...`（按选项顺序生成）
  - 多选（type=2）：字母升序拼接，如 `AB`
  - 判断（type=3）：`正确` / `错误`
  - 填空/简答（type=4/5）：文本
- **交卷**：`POST /study/exams/records/{recordId}/submit`，body `{ answers:[{questionId,answer}] }`，返回成绩单。
- **成绩页**：`GET /study/exams/records/{recordId}/result`，展示得分、是否通过、逐题解析（正确/错误答案、解析）。

### 3.3 个人中心与培训档案

- **个人资料**：展示并修改手机号、邮箱（`PUT /study/profile`）；修改密码（`PUT /study/profile/password`）。
- **学习记录**：`GET /study/records/study`，展示课程/视频/时长/进度/完成状态。
- **成绩单**：`GET /study/records/exam`，展示试卷/得分/是否通过/提交时间。
- **培训档案**：`GET /study/records/certificate`，按证书状态 `valid/expiring/expired/not_pass` 配色。

## 4. 开发顺序

1. 公共层：`utils/request.js`、`app.js`（存储键）、登录页（验证码）。
2. 任务链路：我的任务 → 全部任务 → 任务详情 → 在线学习。
3. 考试链路：须知 → 答题 → 成绩。
4. 个人中心链路：个人中心 → 学习记录 → 培训档案；消息中心；课程中心。
5. 工程收口：`app.json` 页面注册与 tabBar、`pages/video/play.json` 补齐、路径与接口一致性检查。

---

## 5. 约定与注意事项

- 所有 JS/WXML/WXSS 代码按项目约定添加**逐行中文注释**。
- 统一时间展示口径为 `yyyy-MM-dd HH:mm:ss`。
- 小程序无 CLI 构建，验证方式为：语法与路径一致性检查 + 后端接口冒烟（`/study/**` 均可访问）。
- 开发调试需在微信开发者工具中勾选「不校验合法域名」，以便访问 `http://localhost:8080`。
