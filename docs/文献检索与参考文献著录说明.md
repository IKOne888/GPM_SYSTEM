# 文献检索与参考文献著录说明

> 用途：指导本课题《基于 Spring Boot 与微信小程序的药品生产企业 GMP 培训管理系统设计与实现》的参考文献检索与著录。
> 原则：**所列文献必须真实存在且可查证**。本说明仅提供检索与著录方法，不提供任何未经核实的文献条目。

## 三、检索策略

### 3.1 关键词组合与布尔逻辑

1. **中文检索**：使用主题/篇名/摘要字段，以 `AND`、`OR` 组合关键词。
   - 示例：`(篇名=培训管理系统) AND (主题=GMP)`；
   - 示例：`(主题=微信小程序) AND (主题=移动学习)`。
2. **外文检索**：同时检索同义词与缩写。
   - 示例：`("spring boot" OR "spring framework") AND ("management system")`。

### 3.2 字段与限定条件

- **字段限定**：优先限定「篇名」或「主题」，避免全字段检索带来的噪声；
- **时间限定**：技术类文献优先近 5 年（2020 年及以后）；权限模型等基础理论可适当放宽；
- **文献类型**：优先「期刊论文」与「会议论文」，学位论文可作为参考。

### 3.3 筛选标准

1. 优先**北大核心 / CSSCI / SCI / EI** 收录期刊；
2. 优先被引次数较高、发表于权威期刊或顶级会议的文献；
3. 剔除来源不明、期刊信息不全、无法核实出处的条目。

---

## 四、文献管理与核实

1. 使用 **NoteExpress / EndNote / Zotero** 等工具管理文献，直接从数据库**导出标准著录格式**，避免手工录入出错；
2. 导出后**逐条核对**：作者、题名、刊名、年份、卷、期、页码、DOI 是否完整；
3. 保存**检索截图或题录导出文件**作为凭证，以备答辩时说明文献来源。

---

## 五、GB/T 7714—2015 著录格式

本课题参考文献按国家标准 **GB/T 7714—2015《信息与文献 参考文献著录规则》** 著录。常用类型格式如下：

| 文献类型 | 标识 | 著录格式 |
| --- | --- | --- |
| 期刊论文 | [J] | 主要责任者. 题名[J]. 刊名, 年, 卷(期): 起止页码. |
| 会议论文 | [C] | 主要责任者. 题名[C]//论文集名. 出版地: 出版者, 出版年: 起止页码. |
| 学位论文 | [D] | 主要责任者. 题名[D]. 城市: 学校, 年. |
| 专著 | [M] | 主要责任者. 书名[M]. 版本. 出版地: 出版者, 出版年: 页码. |
| 标准 | [S] | 标准编号, 标准名称[S]. 出版地: 出版者, 出版年. |
| 电子文献 | [EB/OL] | 主要责任者. 题名[EB/OL]. (发布日期)[引用日期]. 网址. |

### 著录要点

1. **作者**：3 名以内全部列出，超过 3 名列出前 3 名后加「, 等」；
2. **页码**：期刊论文必须给出起止页码；会议论文给出在论文集内的页码；
3. **电子文献**：[EB/OL] 须注明**引用日期**与**完整网址**；
4. **标点**：严格按上述格式使用英文标点（`.`、`,`、`:`）。

### 示例（格式示范，非本课题文献）

- 期刊：`[J] 张三, 李四. 某管理系统的设计与实现[J]. 计算机应用, 2022, 42(3): 100-105.`
- 会议：`[C] Smith J. A study on X[C]//Proceedings of the International Conference on Y. New York: ACM, 2021: 12-20.`
- 电子文献：`[EB/OL] 微信开放社区. 微信小程序开发文档[EB/OL]. [2026-10-15]. https://developers.weixin.qq.com/miniprogram/dev/framework/.`

> 上例仅示范标点与字段顺序，**不得直接作为文献引用**。

## 六、操作流程建议

1. 按第一、三节确定检索式，在 CNKI/万方等库检索；
2. 按第四节筛选标准选出候选文献，**导出题录**；
3. 按第五节格式**核对并统一著录**；
4. 将核实后的文献补入开题报告第 8.4 节（原「待补充」条目），并将编号与正文引用位置对应；
5. **全篇复查**：确保正文中出现的每一处引用，都在文献表中有对应条目；反之亦然。

---

> **底线要求**：凡无法核实出处的文献一律不得列入。宁可条目少，也不编造作者、刊名、卷期与页码。
